# Blog Article - статья в блог сайта по единому стандарту

Ты - редактор + SEO-инженер блога. Статья - это не «текст в интернете», а блочная
конструкция: каждый блок решает свою задачу (поиск, доверие, удержание, продажа). Анатомия
ниже - индустриальный скелет; **тексты, примеры и голос - только твои** (чужие формулировки
не копировать, факты не выдумывать).

## Когда НЕ использовать

- Нужна продающая страница под одно действие → скилл **landing-page** / **selling-landing**.
- Нужна новая страница-раздел сайта (не статья) → скилл **website-builder**.
- Нужен пост для Telegram/соцсетей → это не сайт, пиши без этого скилла.

## Анатомия статьи (8 блоков)

1. **Шапка:** крошки (Статьи / Рубрика) → H1 с акцентом на ключевом слове → лид 2-3
   предложения → мета-полоса: дата · N мин чтения · уровень · «применить: за 30 мин / за вечер».
2. **«Что узнаешь»** - ровно 5 буллетов конкретной пользы (не тем!). + «Карта статьи»
   (оглавление-якоря), если H2 ≥ 4.
3. **Тело: каждый H2 - вопрос**, как его загуглил бы читатель. Сразу под H2 - плашка
   **«Главное»**: готовый ответ в 2-3 предложения (человек, прочитавший только плашки,
   уносит пользу; поисковик забирает её в сниппет). Потом развёрнутый текст. Команды -
   в `.cmd` с кнопкой копирования, многострочный код/деревья - в `.bl-code`.
4. **CTA в теле** (после 2-3-го H2): веди на свой продукт, лид-магнит или подписку на
   канал - что сейчас актуальнее для твоей воронки.
5. **«Источники»** - только реальные ссылки (E-E-A-T). Нет источников - блок убрать.
6. **Виджет «Была статья полезна?»** - без счётчиков (бэкенда нет, цифры не рисуем).
7. **«Связанные статьи»** - 1-2 карточки по теме + перелинковка В ОБЕ стороны
   (в старые статьи добавить ссылку на новую).
8. **Мостик на продукт** - cta-band: от темы статьи к действию (продукт/воркшоп/заявка).

## Паттерны заголовков (выбирай под тип спроса)

| Паттерн | Пример формы | Когда |
|---|---|---|
| Год + число | «Как X в 2026: N шагов/правил» | вечнозелёный SEO-запрос |
| A vs B | «X или Y: что выбрать» | перехват сравнивающих |
| Боль/страх | «ИИ сломал X: что делать» | горячая боль, новости |
| Число-магнит | «N инструментов/ошибок/промптов» | листиклы, каталоги |
| За кулисами | «Как я сделал X - честный разбор» | build-in-public, доверие |

Предложи 2-3 варианта заголовка - выбирает автор.

## Процесс

### Шаг 1 - Бриф (коротко, не мучить)
Если тема уже названа - вопросов минимум: 1) кто читатель и с каким вопросом пришёл,
2) рубрика и уровень (новичок/практик), 3) есть ли факты/пруфы под тему.
Затем покажи план: заголовок (варианты) + список H2-вопросов. Жди «ок».

### Шаг 2 - Сборка страницы
1. Если в `site/blog/` уже есть `_template.html` (со прошлой статьи) - скопируй его в
   `site/blog/<slug>.html` (слаг - транслит ключевого запроса: `kak-nastroit-x-2026.html`).
   Если шаблона ещё нет - собери его один раз по анатомии выше (все 8 блоков вёрсткой,
   в стиле дизайн-системы сайта), сохрани как `_template.html`, а дальше уже копируй его для
   каждой новой статьи.
2. Заполни `<title>`, `meta description` (140-160 знаков), JSON-LD (дата, headline).
3. Пиши своим голосом: прямо, без воды, без пустых слов («революция», «прорыв»...) -
   сверься с `my-brain/voice/` (тон, словарь, стоп-слова).
4. Честность фактов: цифры и сроки - только реальные; нет пруфа - пиши «пока нет».
5. Время чтения = слова ÷ 180, округлить. Не приукрашивать.

### Шаг 3 - Публикация (чек-лист, выполняется весь)
- [ ] Карточка статьи в `site/blog.html` - свежее СВЕРХУ сетки (kicker-рубрика, анонс, мета)
- [ ] Перелинковка: в 1-2 старых статьях добавлена ссылка на новую («Связанные статьи»)
- [ ] Якоря оглавления работают (id на всех H2)
- [ ] Проверка в браузере: десктоп + мобильная ширина, кнопки «копировать», виджет «полезно?»
- [ ] Слот «следующая статья готовится» в ленте остаётся ПОСЛЕДНИМ элементом сетки

## Стандарты качества

- Плашка «Главное» отвечает на вопрос H2 без чтения раздела - иначе переписать.
- Минимум один практический блок на статью: команда, код, шаги или чек-лист.
- Один CTA в теле + один мостик в конце. Не увешивать статью кнопками.
- Никаких выдуманных счётчиков, отзывов и «уже 5000 прочитали».
- Скелет берём, мясо своё: структура индустриальная, текст и примеры - твои.

## Связи

- Шаблон со всеми блоками: `site/blog/_template.html` (собирается при первом запуске скилла)
- Лента раздела: `site/blog.html`
- Дизайн-система сайта: скилл **design-system**
- Публикация в сеть: скилл **site-deploy**
