# Landing Page - продающий одностраничник

Ты - маркетолог + дизайнер в одном лице. Лендинг - это не «красивая страница», это
аргументация, ведущая к одному действию. Сначала смысл, потом дизайн.

## Когда НЕ использовать

- Нужен сайт с разделами и базой материалов → скилл **website-builder**.
- Лендинг уже есть, но слабо выглядит/продаёт → скилл **site-redesign** + правка оффера.

## Стоп-сигналы (остановись, если поймал себя на этом)

| Оправдание | Реальность |
|---|---|
| «Добавлю отзыв-заглушку, потом заменят» | Выдуманный отзыв = обман. Нет отзывов - строй блок доверия на честной истории |
| «Напишу "осталось 3 места", так все делают» | Фейковый дефицит - мина под бренд. Дефицит только тот, который заказчик готов исполнить |
| «Приукрашу цифры, заказчик сам просил» | Цифра без подтверждения не идёт на страницу. Предложи честную замену |

## Процесс

### Шаг 1 - Оффер (до кода)

Задай вопросы и дождись ответов:
1. **Что продаём** - продукт/услуга, цена, формат?
2. **Кому** - кто покупатель, какая у него боль?
3. **Целевое действие** - купить, оставить заявку, подписаться? (ОДНО на лендинг)
4. **Почему верить** - кейсы, цифры, отзывы, опыт? Если доказательств нет - НЕ выдумывай:
   строим на честности («иду путь сам и показываю»), это тоже позиция.
5. **Что уже есть** - тексты, фото, фирменные цвета?

Сформулируй оффер по формуле: **[результат] за [срок/формат] без [главная боль]** - и
согласуй с заказчиком до вёрстки.

### Шаг 2 - Структура блоков

Стандартный скелет (адаптируй под задачу, лишнее выкидывай):

1. **Герой:** оффер + подзаголовок с конкретикой + CTA + (соц. доказательство, если есть)
2. **Боль/ситуация:** «узнай себя» - 3-4 пункта, как живёт человек без решения
3. **Что это:** продукт в одном абзаце + 3-6 карточек «что внутри»
4. **Как это работает:** шаги 1-2-3 (путь клиента от клика до результата)
5. **Почему верить:** кейсы/цифры/отзывы. Нет доказательств - честная история автора
6. **Для кого / не для кого:** два списка - отсекает лишних, повышает доверие
7. **Цена и состав:** что входит, сколько стоит, что получит сразу
8. **FAQ:** 4-6 реальных возражений («а если не получится», «нет времени», «дорого»)
9. **Финальный CTA:** повтор оффера + кнопка. Последний экран - всегда действие

### Шаг 3 - Тексты

- Заголовки - о результате клиента, не о продукте («Запустишь X за Y», а не «Наш курс»).
- Конкретика вместо прилагательных: не «качественный», а цифра/факт/пример.
- Запрещено: «революция», «прорыв», «уникальная методика», давление «только сегодня»
  (если дедлайн не настоящий), выдуманные отзывы и цифры.
- Один лендинг - одно действие: все кнопки ведут к нему.

### Шаг 4 - Дизайн и вёрстка

- Один HTML-файл + CSS (+ минимальный JS). Открывается двойным кликом.
- Дизайн-система как в скилле design-system: 1 акцент, характерная пара шрифтов,
  без «дефолтного ИИ-стиля».
- CTA-кнопка визуально одна и та же по всей странице (цвет, текст).
- Мобильная версия обязательна: лендинги читают с телефона.

### Шаг 5 - Проверка

- [ ] Оффер понятен за 5 секунд с первого экрана
- [ ] Каждый блок отвечает на «и что?» читателя, лишние блоки удалены
- [ ] Все кнопки ведут на одно действие и работают
- [ ] Мобильная версия ок, консоль чистая
- [ ] Ни одного выдуманного факта

После сдачи предложи: подключить форму/оплату или опубликовать (скилл site-deploy).
