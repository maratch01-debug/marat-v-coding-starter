# Арсенал: законы продаж, конверсии и власти под лендинг

Справочник к скиллу **selling-landing**. Читать перед написанием текстов страницы. Это рычаги -
бери под задачу, комбинируй. Разбито на 3 части: фундамент конверсии → 48 законов власти под
лендинг → разбор приёмов топов рынка.

---

## Часть 1. Фундамент конверсии (обязательная база)

### 7 принципов влияния (Чалдини)
| Принцип | Рычаг на странице |
|---|---|
| **Взаимность** | Дай ценность до продажи: бесплатный кусок, гайд, разбор в самом лендинге - долг «отплатить». |
| **Обязательство/последовательность** | Веди к мелким «да» (3 вопроса перед ценой, квалификация «тебе сюда») - крупное «да» становится логичным продолжением. |
| **Социальное доказательство** | Отзывы, цифры, «уже собрали N». Два эшелона: короткие под героем, развёрнутые перед ценой. |
| **Авторитет** | Кейсы, пруфы, регалии, демонстрация экспертизы. Нет статуса - авторитет через «показываю, как делаю». |
| **Симпатия** | Живое лицо, свой голос, «я был в твоей точке А». Люди покупают у тех, на кого похожи/кому симпатизируют. |
| **Дефицит** | Ограничение мест/времени/цены - но с реальным механизмом. Дефицит усиливает ценность. |
| **Единство** | «Мы одной крови»: общая идентичность, ниша, боль. «Для таких же, как ты». |

### Уравнение ценности (Хормози)
**Ценность = (Мечта × Вера в достижимость) ÷ (Время до результата × Усилия)**
На странице: конкретизируй мечту (точка Б), докажи достижимость (кейсы/демо), подчеркни СКОРОСТЬ
(«результат уже на первом уроке») и ЛЁГКОСТЬ («нужен только браузер, промпты готовы»). Работай над
всеми 4 рычагами - слабый знаменатель убивает даже сильную мечту.

### Формулы длинного текста
- **PAS** (Problem → Agitate → Solution): назови боль → усиль последствия бездействия → дай выход.
  Люди сильнее бегут ОТ боли, чем К выгоде (Кеннеди).
- **AIDA** (Attention → Interest → Desire → Action): каркас всей страницы сверху вниз.
- **Специфичность обещания:** не «развивай блог с ИИ», а «контент-план на месяц за вечер». Мечта
  «ни для кого» не продаёт - только измеримый результат.
- **Voice of customer:** боли брать дословно из слов аудитории (кастдев, комменты), не из головы.

### Ключевые приёмы (техники)
| Приём | Как применить |
|---|---|
| **Фасцинации (открытые петли)** | 6-10 буллетов-загадок с ответом только внутри: число + отрицание очевидного + контр-интуиция. |
| **Future pacing** | Детально описать день/неделю в точке Б - мозг проживает результат до покупки. |
| **Якорение цены** | Сначала большая сумма (стек ценности / реальная альтернатива), потом реальная цена - контраст. |
| **Провенанс якоря** | Каждую цифру якоря подкрепить фактом («монтажёр берёт X»), а не выдуманным ценником. Якорь работает от обоснованности, не от размера. |
| **Reason-why** | Любое обоснование низкой цены/действия повышает согласие («первый поток - собираю кейсы»). |
| **Реверс риска (гарантия)** | Смелее гарантия → выше конверсия; возвратов на мини-продукте единицы. Привязка к результату сильнее срока. |
| **Драма снижения** | «Не 51 000 → не 25 000 → не 3 000 → всего N» - последовательное падение цены. |
| **Ценовой рефрейм** | «N ₽ - это не цена, это фильтр на тех, кто сделает» + бытовое сравнение («две чашки кофе»). |
| **Тарифы good/better/best** | Премиум якорит, средний - «разумная середина»; спор смещается с «брать?» на «какой?». |
| **Take-away selling** | «Не возьмёшь - нормально, метод проб тоже путь, просто дольше». Отказ от давления повышает доверие. |
| **P.S.-приём** | Постскриптум с сильнейшим аргументом (гарантия + выгода) - самая читаемая часть после заголовка. |
| **Множественные CTA** | Кнопка после каждого блока: человек созревает в разный момент скролла. |
| **Самосегментация** | «Тебе сюда, если… / не сюда, если…» - отсев поднимает ценность, читатель сам себя записывает. |

## Часть 2. Ключевые законы власти под лендинг (подмножество из 48)

Из книги Р. Грина «48 законов власти» (публичная, законы стратегии влияния). Здесь - отобранные
законы, которые прямо переносятся на продающую страницу, и как каждый работает как маркетинговый
рычаг. Остальные законы книги - про интриги в коллективе и меньше применимы к лендингу. Бери те,
что усиливают оффер.

| # | Закон | Рычаг на лендинге |
|---|---|---|
| 1 | Не затмевай господина | Герой страницы - клиент и его результат, не ты. Ты - проводник. |
| 4 | Говори меньше, чем нужно | Недосказанность в буллетах-фасцинациях - ответ только внутри продукта. |
| 5 | Репутация - краеугольный камень | Соц-доказательство и кейсы охраняй; один фейк рушит всё. |
| 6 | Привлекай внимание любой ценой | Смелый герой, тёмная вставка, контр-интуитивный заголовок - выделись в ленте. |
| 7 | Пусть работа будет сделана, лавры - твои | Демо «сделано за тебя» (продукт уже выдаёт результат) - покупают снятие труда. |
| 9 | Побеждай делами, не спорами | Показ вместо рассказа: анимация продукта в действии > абзаца убеждений. |
| 10 | Держись подальше от несчастливых | «Не для тех, кто ищет кнопку бабло» - отсекай нецелевых, притягивай «победителей». |
| 11 | Держи людей в зависимости от себя | Продуктовая лестница: трипваер → следующий продукт. Открытая петля на большее. |
| 12 | Обезоружь искренностью | Одна честная слабость («у меня нет миллиона подписчиков») повышает доверие ко всему. |
| 13 | Взывай к интересам, не к милости | Всё в терминах ЕГО выгоды («что ТЫ унесёшь»), не «купи, мне надо». |
| 15 | Разбей врага полностью | Демонтируй ВСЕ возражения (7 «я не смогу»), не оставляй лазеек для «нет». |
| 16 | Отсутствие усиливает уважение | Дефицит, «беру не всех», лимит мест - редкость поднимает ценность. |
| 17 | Держи в напряжении непредсказуемостью | Открытые петли, «а в конце расскажу…» - удерживают до низа страницы. |
| 20 | Не примыкай ни к кому (будь своей категорией) | Своя методология под своим именем - не «ещё один курс», а отдельная категория. |
| 25 | Твори себя заново | Свой бренд-персонаж, айдентика, тон - не сливайся с конкурентами. |
| 27 | Играй на потребности в вере | Большая идея/манифест, во что верит бренд - люди идут за смыслом, не за уроками. |
| 28 | Действуй дерзко | Уверенный оффер и заголовок без извинений («собери завод за 3 вечера»), не «попробуйте, вдруг». |
| 32 | Играй на фантазиях | Точка Б, future pacing, картина новой жизни - продаём мечту, не набор файлов. |
| 34 | Веди себя по-царски | Премиум-подача даже дешёвого продукта: продукт ощущается дороже цены. |
| 35 | Искусство точного расчёта времени | Настоящая срочность (цена потока до даты X), не вечный фейк-таймер. |
| 36 | Презирай то, чего не можешь иметь | Мягкий take-away: «не готов - ок, вернёшься позже» - игнор давления притягивает. |
| 37 | Твори завораживающие зрелища | Визуал: тёмная вставка, анимации, демо-конвейер - шоу удерживает взгляд. |
| 44 | Обезоруживай эффектом зеркала | Voice of customer: боли его словами - «это же про меня, они меня понимают». |
| 46 | Не выгляди слишком совершенным | Честная точка А, «иду путь сам» - неидеальность делает своим, а не «гуру с картинки». |

Правило применения: законы - усилители оффера, а не замена сути. Дерзость (з.28) и напряжение
(з.17) работают, только когда за ними стоит реальная ценность (з.9 - побеждай делами).

## Часть 3. Разбор приёмов топов рынка (синтез)

Снято с разборов сильных русских воронок (мини-продукты 990-9900 ₽). Скелет и рычаги берём;
своё — тексты, айдентика, личность.

### Структурные ходы
- **Заход «дело не в тебе»** - открыть снятием вины: «навык есть, просто систему никто не собрал».
  Облегчение открывает к чтению.
- **Продажа преодоления барьера, а не технологии** - ЦА уже прошла курсы, но не начала. Продавать
  первый доведённый результат, не «знания».
- **Результат-артефакт по ссылке** - обещать демонстрируемую вещь (живой канал/проект), которую
  можно показать. Покупают возможность предъявить.
- **Двойная квалификация «тебе сюда / не сюда»** - два списка, отсев поднимает ценность.
- **Список «что НЕ нужно»** - снести 5-7 отговорок разом (лицо, монтаж, команда, бюджет, код).
- **UI-сторителлинг** - анимированный показ продукта в работе («✓ пост собран → опубликовано → +1.2к»).
- **Self-demo** - «эта страница/канал собраны тем самым продуктом, которому учу» + ссылка.
- **Продукт как механизм** - упаковать в одну систему со своим названием, не «урок 1,2,3».
- **Персонализация «выбери свой путь»** - N вариантов под N типов людей, каждый видит себя.

### Ценовые механики (с цифрами рынка)
- Трипваер 990 ₽ + якорь 51 580 ₽ (сумма «обычных цен» + бонусы) + драма снижения + сравнение с
  пиццей + рефрейм «990 - фильтр». Слабость: выдуманные ценники бонусов якорю не верят.
- Order bump на кассе: +2620 ₽ к чеку 990 («83% берут, больше недоступно») → средний чек ×3.6.
- Тарифы 2990 / 3990 / 9990: премиум якорит, стандарт - середина.
- Якорь 51 000 из ОБОСНОВАННЫХ компонентов + провенанс («за это заплатил $1500») - работает от
  обоснованности. Скидка абсолютом: «83% - это минус 41 010 ₽».
- Тройной стек гарантий: (1) не окупишь - верну вдвое; (2) 60 дней без вопросов; (3) дефицит-«оффер
  сгорит». На точке А без выручки - начинать с ОДНОЙ честной гарантии.
- Единая цена без сетки + «9 900 (не ошибка)» обыгрывает недоверие к цене. Убрать трение оплаты:
  рассрочка, помощь с оплатой, счёт юрлицу. Дефицит - прогресс-бар «Поток 12, заполнено 33%».
- Freemium: 0 ₽ (часть) → VIP 990 ₽ → апселл «19 900 бесплатно внутри VIP при оплате за 24ч».

### Диапазон рынка для мини-продукта
Чек в рынке: 990-6900 ₽. Механика под низкий чек: якорь только с провенансом, reason-why «первый
поток», одна честная гарантия возврата, order bump для среднего чека, дефицит только реальный.

### Что НЕ копировать (принцип границы)
- Чужие тексты, буллеты, программы дословно - только скелет и рычаги, мясо своё.
- Чужой тон/эстетику/личность (капс, мат-новояз, «эксперт №1») - это их бренд, не твой.
- Раздутые непроверяемые обещания и выдуманные кейсы «2.3 млн» - под репутацию мина.
- Якорь из выдуманных ценников бонусов + вечный фейк-таймер - теряет доверие и рискует по закону
  о рекламе.
- Регалии, которых нет - имитировать нельзя; источник доверия строй на реальном (демо, процесс).
