# Скиллы — база знаний

> Библиотека готовых скиллов для Claude Code. 13 инструментов под сайты, контент и стратегию.
> Каждый скилл - отдельная папка с файлом `SKILL.md`.

## Что такое скилл

Скилл - это инструкция, которая «прокачивает» Claude под конкретную задачу. Установил - и
Claude делает работу не «как получится», а по проверенной системе: с правильными вопросами,
процессом и стандартом качества.

## Как установить

Если ты клонировал весь стартер-пак - скиллы уже здесь, ничего доустанавливать не надо,
Claude Code подхватывает папку `skills/` в корне проекта автоматически.

Хочешь использовать скилл в ДРУГОМ своём проекте - скопируй его папку (например
`website-builder/`) в:
- **Для всех проектов:** `C:\Users\<имя>\.claude\skills\` (Windows) или `~/.claude/skills/` (Mac)
- **Для одного проекта:** `<проект>\.claude\skills\`

Перезапусти Claude Code. Дальше пиши запрос по теме («сделай мне лендинг») - скилл
подхватится сам, или вызови напрямую: `/website-builder`.

## Скиллы по созданию сайтов

| Скилл | Что делает | Когда брать |
|---|---|---|
| [website-builder](website-builder/SKILL.md) | Собирает полноценный многостраничный сайт с нуля: вопросы → дизайн-система → страницы → проверка | Нужен свой сайт/база знаний/сайт-система |
| [landing-page](landing-page/SKILL.md) | Продающий одностраничник: оффер, структура блоков, CTA | Нужна быстрая честная страница под продукт/услугу/воронку |
| [marketing_laws](marketing_laws/SKILL.md) | МАКСИМАЛЬНО продающая длинная страница-воронка: 14-18 блоков, инженерия блока цены, анимации, арсенал законов продаж/конверсии + 48 законов власти ([laws.md](marketing_laws/laws.md)) | «Полный фарш», выжать конверсию мини-продукта/воркшопа; запускать в связке с design-system |
| [design-system](design-system/SKILL.md) | Палитра, шрифты, токены - фирменный вид без «дефолтного ИИ-стиля» | Перед любым сайтом или для единого стиля |
| [site-redesign](site-redesign/SKILL.md) | Аудит и апгрейд существующего сайта без поломки | Сайт есть, но выглядит дёшево/устарело |
| [site-deploy](site-deploy/SKILL.md) | Публикация сайта в интернет + домен | Сайт готов, нужен адрес в сети |

## Скиллы по контенту

| Скилл | Что делает | Когда брать |
|---|---|---|
| [viral-remix](viral-remix/SKILL.md) | Конвейер репликации виральных роликов: разбор чужой виралки → адаптация под свой голос → концепт с апрувом → раскадровка → съёмка → чек-лист → замер | Кидаешь ссылку на залетевший ролик - получаешь производство своего по той же механике |
| [content-factory](content-factory/SKILL.md) | Из одного финального сценария длинного видео за проход делает 21 копипаст-готовую единицу: 1 статья + 10 тредсов + 5 рилсов + 5 постов в твоём голосе и с антиИИ-фильтром, раскладка в 4 файла | Есть сценарий длинного видео - «размножь его на контент под все площадки» |
| [video-montage](video-montage/SKILL.md) | Монтаж рилса через ffmpeg: наложить хук на видео, вписать в 1080×1920, субтитры, музыка, PiP-пруф, батч. Готовый скрипт `render-hook.sh`, проверен рендером | «Наложи хук на это видео», «сделай рилс из этого» - без монтажёра и приложений |
| [blog-article](blog-article/SKILL.md) | Статья в раздел блога сайта по единой анатомии: H2-вопросы + плашки «Главное», источники, перелинковка, CTA-мостик; сборка из шаблона + карточка в ленте | «Напиши/опубликуй статью про X» - от темы до опубликованной страницы одной командой |
| [humanizer-ru](humanizer-ru/SKILL.md) | Убирает следы ИИ из русского текста: 27 паттернов с примерами «до/после» (раздувание значимости, канцелярит, вводные, тире, эмодзи, ёлочки, вода) + добавляет живой голос | «Почисти текст», «звучит как ИИ», «сделай по-человечески» |

## Скиллы по стратегии и разбору

| Скилл | Что делает | Когда брать |
|---|---|---|
| [competitor-analysis](competitor-analysis/SKILL.md) | Разбор конкурента по методу «границы»: определяет тип (аккаунт/продукт/платформа) → раскладывает по механике → приёмы влияния нейтрально → воронка → **обязательный вывод «что берём / что НЕ берём»** + архив чужих текстов дословно | Кидаешь ссылку/скрины конкурента - получаешь структурный разбор и банк гипотез/хуков/офферов под свою нишу |

## Порядок для новичка

```
design-system → website-builder (или landing-page/marketing_laws) → site-deploy
```

Сначала фирменный вид, потом сборка, потом публикация. Дальше - `blog-article` для контента
на сайт, `content-factory` + `video-montage` для конвейера роликов и постов, `competitor-analysis`
и `viral-remix` - когда нужен референс со стороны. Редизайн - отдельная ветка, когда сайт уже есть.

## Что можно собрать этим набором

- **Личный сайт/платформа** - website-builder + design-system + blog-article + site-deploy.
- **Продающий лендинг под продукт** - landing-page или marketing_laws (полный фарш) + design-system.
- **Ежедневный контент-конвейер** - viral-remix/content-factory на заготовки → video-montage на монтаж → humanizer-ru на чистку текста.
- **Стратегия и позиционирование** - competitor-analysis, чтобы не выдумывать нишу с нуля, а опереться на разобранных конкурентов.

## Правила пополнения базы

- Один скилл = одна задача (не «скилл про всё»).
- Имя папки - английское, kebab-case. Контент - на русском.
- Внутри `SKILL.md`: фронтматтер (name, description) + процесс по шагам + стандарты качества.
- Новый скилл → добавь строку в таблицу выше.

## Связи

- Библиотека промптов (не скиллов) - `prompts/INDEX.md`
- Второй мозг, откуда скиллы берут голос и нишу - `my-brain/`
- Сайт, который ты соберёшь этими скиллами, - `site/` (появится после первого запуска website-builder)
