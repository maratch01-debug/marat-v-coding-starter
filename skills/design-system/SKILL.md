# Design System - фирменный вид без «ИИ-дефолта»

Ты - арт-директор. Задача: за 15 минут дать проекту лицо, которое не спутаешь с тысячей
шаблонных сайтов. Результат - файл `styles.css` с токенами + короткая шпаргалка «как этим
пользоваться».

## Когда НЕ использовать

- У проекта уже есть дизайн-система/брендбук → используй её, вторую не изобретай.
- Нужен весь сайт целиком → скилл **website-builder** (этот шаг там встроен).

## Шаг 1 - Три вопроса заказчику

1. **Характер** - каким должен ощущаться бренд? (спокойный эксперт / дерзкий боец /
   тёплый наставник / технологичный продукт...)
2. **Светлый или тёмный?**
3. **Есть ли якоря** - существующий логотип, любимый цвет, примеры «нравится/не нравится»?

Если ответов нет - предложи 2-3 направления по одной фразе и дай выбрать.

## Шаг 2 - Палитра (формула)

Ровно 6-8 переменных, не больше:

```css
:root {
  --bg:        /* фон: НЕ чисто-белый и НЕ #000. Тёплый или холодный оттенок */
  --surface:   /* карточки/секции: на полтона от фона */
  --ink:       /* текст: тёмный с оттенком, не #000 */
  --ink-soft:  /* вторичный текст */
  --line:      /* линии и рамки */
  --accent:    /* ОДИН акцент - кнопки, ссылки, детали */
  --accent-ink;/* акцент для текста на светлом (темнее) */
}
```

Правила:
- Один акцент. Второй цвет - только как едва заметная поддержка (заливка бейджа).
- Фон с характером: тёплая бумага (#F4F1EA), холодный графит (#101318), кремовый - что
  угодно, кроме #FFFFFF и стандартного #F9FAFB.
- **Запрещено:** фиолетово-синий градиент на белом (главный штамп ИИ-сайтов), неон на
  чёрном «как у всех», радуга из 5+ цветов.

## Шаг 3 - Шрифты (пара с Google Fonts)

Формула: **характерный дисплейный + спокойный текстовый (+ mono для деталей)**.

Проверенные пары под характер:
- Спокойный эксперт: Fraunces + IBM Plex Sans
- Editorial/журнал: Playfair Display + Source Sans 3
- Технологичный: Space Grotesk + Inter (Inter - ТОЛЬКО текстом, не заголовками)
- Дерзкий: Archivo Black + Archivo
- Тёплый: Lora + Nunito Sans

Правила: заголовки clamp() (крупные на десктопе, живые на мобиле), letter-spacing -0.01em
на крупных, mono - для лейблов-eyebrow ВЕРХНИМ РЕГИСТРОМ с letter-spacing 0.1em+.

## Шаг 4 - Токены ритма

```css
--maxw: 1120px;      /* ширина контента */
--radius: 14px;      /* один радиус на всё (или 2: карточки/кнопки) */
--shadow: ...;       /* одна мягкая тень, без чёрных пятен */
--gap: clamp(1rem, 2vw, 1.5rem);
```

Секции: `padding: clamp(3.5rem, 8vw, 6.5rem) 0` - воздух решает больше, чем декор.

## Шаг 5 - Сдача

Выдай:
1. `styles.css` - переменные + база (типографика, кнопки, карточки, секции).
2. Мини-страницу `preview.html` - палитра, шрифты, кнопка, карточка на одном экране.
3. Шпаргалку в 5 строк: «акцент - только на действие; воздух - между секциями; один радиус;
   eyebrow над каждым заголовком; ничего чисто-белого/чисто-чёрного».

Финальный тест: если убрать логотип - сайт всё ещё узнаваем? Если нет - характера мало,
усиливай (цвет фона, шрифт заголовков, фактура).
