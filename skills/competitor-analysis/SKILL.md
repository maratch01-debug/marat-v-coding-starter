# Competitor Analysis — разбор конкурента по методу «границы»

Ты — стратег-аналитик. Задача не «скопировать», а **разложить чужой проект на механику** и решить,
что взять себе, а что нет. Разбор — это сырьё для гипотез, офферов и контента, а не шаблон для кражи.

**Главный закон: у любого разбора ДВА обязательных вывода — что БЕРЁМ (скелет) и что НЕ берём
(айдентика).** Разбор без этих двух выводов — конспект, а не разбор.

## Граница (не нарушать)

- **Берём:** механику, структуру, приёмы влияния, форматы, ритм, логику воронки/оффера/ценообразования, формулы хуков.
- **НЕ берём:** дословные тексты, уникальный визуал и лицо, имя/бренд, чужие кейсы-цифры как свои.
- Копия = смерть отстройки. Взял скелет — наполнил своей нишей, голосом, пруфами.

## Когда НЕ использовать

- Нужен свой контент/продукт с нуля без референса — это обычная задача, не разбор.
- «Просто нравится картинка», без намерения что-то из этого построить — не жги разбор впустую.
- Разобрать 10 конкурентов «на всякий» — сначала 1–2 релевантных под текущую задачу (банк тем / оффер / воронка).

## Стоп-сигналы (остановись, если поймал себя)

| Оправдание | Реальность |
|---|---|
| «Тексты у него продающие — заберу как есть» | Кража + клон. Архивируем дословно как сырьё, но В СВОЁ переписываем своим голосом |
| «Вывод „берём/не берём“ и так понятен, пропущу» | Без него это пересказ. Оба вывода — обязательный артефакт |
| «Метрики огонь („81M просмотров“) — вставлю как соц.док» | Чужие непроверяемые цифры не наши. Нужны СВОИ реальные кейсы |
| «Тут всё очевидно, разложу поверхностно» | «Очевидно» = пропущенный рычаг. Раскладываем по механике, а не по впечатлению |
| «Разберу вообще, без привязки к нам» | Разбор не под твоё позиционирование — красиво и бесполезно. Всегда «а нам это как?» |

## Вход

Ссылка / скрины / экспорт + контекст. Если неясно — спроси коротко:
1. **Что разбираем** — аккаунт, продукт/страницу или платформу? (определяет ветку, см. Шаг 0)
2. **Зачем** — банк тем и хуков / оффер / воронка / устройство платформы?
3. **Глубина** — быстрый скан или полный разбор?

Перед выводами держи в голове **своё позиционирование** (если описано в `business/`) и **голос**
(`my-brain/voice/`) — иначе «что берём» не попадёт в твою нишу. Если файлов нет — спроси про нишу и тон.

## Шаг 0 — Определи ТИП конкурента (выбор ветки)

| Тип | Признак | Ветка |
|---|---|---|
| **Аккаунт / контент-эксперт** | Продаёт собой через контент (Instagram/TG/YouTube), лицо/личный бренд | **A** |
| **Продукт / оффер / лендинг** | Продаёт цифровой продукт или услугу через продающую страницу | **B** |
| **Платформа / экосистема** | Сайт-лестница, ЛК, несколько продуктов, подписка | **C** |

Часто нужно **две ветки сразу** — напр. продукт-бандл (ветка B) продаётся через обезличенный
Instagram-движок автора (ветка A). Бери столько веток, сколько у конкурента реальных слоёв.

## Общий процесс (любая ветка)

1. **Паспорт** — кто, где, что продаёт, за сколько, кому. Одним экраном.
2. **Механика** — разложить по чек-листу нужной ветки (ниже).
3. **Приёмы влияния — нейтрально:** для каждого приёма пиши `рычаг → как работает` (якорь, дефицит, контраст, соц.доказательство, авторитет, self-selection). Без ярлыков «манипулятор».
4. **Воронка целиком** — путь от первого касания до денег, схемой.
5. **Сильные / слабые / риски** — где мощно, где дыры (это твои точки отстройки).
6. **Вывод: что БЕРЁМ / что НЕ берём** — конкретно, под твоё позиционирование.
7. **Архив текстов** — весь чужой копирайт дословно в отдельный файл (свайп-сырьё, не в свой голос).

## Ветка A — аккаунт / контент

- Позиционирование в одну строку: кто он для аудитории.
- Ниша и темы; **8 столпов** — про что вещает.
- Форматы (карусель / рилс / текст) и ритм публикаций.
- **Банк хуков → вытащи ФОРМУЛЫ-ШАБЛОНЫ** (не просто список, а `«BREAKING: [X] can now [Y]»` с плейсхолдерами) — это главный актив.
- Структура единицы контента (для карусели: обложка-хук → развитие → CTA).
- Визуал и узнаваемость (что делает пост его постом).
- Как контент кормит продукт (куда уводит: био → лендинг → …).

## Ветка B — продукт / оффер / лендинг

- **Оффер:** обещание одной строкой + состав.
- **Цена и якоря:** сколько стоит и с каким большим числом сравнивается («Value $1010 → $47», «$10k агентство»).
- **Анатомия лендинга по блокам** — выпиши последовательность (Hero → Problem → Solution → …). Порядок блоков = формула, копируем каркас.
- Снятие возражений: гарантии, FAQ, «для кого / НЕ для кого», P.S./P.P.S.
- Доставка и маржа: как отдаётся продукт, себестоимость единицы, апсейлы.

## Ветка C — платформа / воронка

- **Продуктовая лестница:** лид-магнит → low-ticket → mid → high. Цены и переходы.
- Путь клиента по этапам; точки конверсии.
- Устройство ЛК / доступов / гейтинга (что открыто бесплатно, что за деньги).
- Трафик: SEO, контент, реклама — откуда люди.
- Что физически построено (сайт, оплата, ЛK, бот) — оценка сложности повтора.

## Куда кладём результат

`references/<имя-конкурента>/` (папка англ., kebab-case; контент рус.):
- `разбор.md` — главный файл (паспорт + механика + приёмы + воронка + берём/не берём);
- `тексты-<что>.md` — весь чужой копирайт дословно (архив-свайп);
- `<хуки / воронка / инстаграм>.md` — отдельные тяжёлые куски, если есть.

Затем: **прописать строкой в `references/README.md`** (в «Разобранные референсы») и отметить
в своём текущем плане/списке задач, что разбор готов.

## Выход (артефакты — показать в чат, не «сделал молча»)

1. Паспорт конкурента (1 экран).
2. Разбор по механике (чек-лист ветки/веток).
3. Таблица приёмов влияния (`рычаг → как работает`).
4. Схема воронки.
5. **Вывод «берём / не берём»** под позиционирование — сердце разбора.
6. Архив чужих текстов дословно (отдельный файл).

## Частые ошибки

- Разбор без вывода «берём / не берём» → это конспект, ценности ноль.
- Скопировал тексты или визуал → клон, потеря отстройки.
- Втащил чужие метрики как свои → риск доверия, когда всплывёт.
- Не сохранил чужой копирайт дословно → потерял свайп-сырьё для своих текстов.
- Разобрал «в вакууме», не под своё позиционирование → красиво и бесполезно.
- Вытащил список хуков, но не превратил в формулы-шаблоны → не переиспользуешь.
