## Что это за проект

**marat-v-coding-starter** — стартовый шаблон для работы с Claude Code. Ты клонировал его,
чтобы ИИ узнал тебя и стал «своим»: знал твою историю, цели, голос — и работал под тебя.

Первый запуск = знакомство (автопилот выше). После него этот `CLAUDE.md` перезапишется на
**твой личный** — с твоим портретом и правилами, а рядом появится папка `my-brain/` (твой
второй мозг).

## Структура репозитория

```
./
├── CLAUDE.md          ← этот файл (после онбординга станет твоим личным)
├── AUTOPILOT.md       ← сценарий знакомства (после онбординга «спит»)
├── README.md          ← что это и как пользоваться
├── my-brain/          ← твой второй мозг: личность, цели, голос (заполнит автопилот)
├── skills/            ← готовые скиллы: инструменты, прокачивающие ИИ под задачи
├── prompts/           ← библиотека готовых промптов (надо X — возьми Y)
├── plans/             ← планы и цикл работы (план → делаешь → итог)
└── sessions/          ← рефлексии после сессий (память между чатами)
```

## Ключевые принципы работы (действуют после знакомства)

1. **Читай `my-brain/` перед задачей про тебя/твой контент.** Не выдумывай — бери из контекста.
2. **Один чат — одна задача.** Разные задачи = разные чаты.
3. **Говори голосом пользователя** (тон и словечки — в `my-brain/voice.md`).
4. **Честность выше комфорта.** Слабую идею назови слабой, но конструктивно.
5. **Точка А → точка Б.** Любой совет привязывай к разрыву «где человек сейчас» и «куда идёт».
