# marat-v-coding-starter

Стартовый шаблон для Claude Code, который **сначала узнаёт тебя, а потом работает под тебя.**

Клонируй → открой в VS Code → напиши любую фразу → ИИ проведёт тебя через знакомство (9 блоков
вопросов о тебе) и соберёт твой личный контекст: кто ты, к чему идёшь, каким голосом говоришь.
Дальше Claude — уже не обезличенный бот, а «свой».

---

## TL;DR

1. Забери шаблон себе (кнопка **«Use this template»** или `git clone`).
2. Открой папку в **VS Code**, открой **Claude Code**, напиши что угодно — `привет`.
3. ИИ сам начнёт знакомство и проведёт через 9 блоков (~40 минут, можно с паузами).
4. На выходе — твой **второй мозг** (`my-brain/`) + личный `CLAUDE.md`. Готово.

## Что ты получаешь

- 🧠 **`my-brain/`** — твой второй мозг: история, личность, ценности, цели, страхи, ниша, голос.
- 📋 **Личный `CLAUDE.md`** — правила, по которым ИИ работает именно под тебя.
- 🧰 **`skills/`** — готовые скиллы Claude Code (инструменты под конкретные задачи).

## Зачем это нужно

Обычный ИИ отвечает «в среднем по больнице» — он тебя не знает. Этот шаблон меняет порядок:
**сначала ИИ узнаёт тебя глубоко, потом помогает.** Чем честнее ответишь на знакомстве — тем
точнее он будет попадать в тебя: твоим голосом, к твоим целям.

## Прежде чем начать

- [ ] Установлен **VS Code**
- [ ] Установлен **Claude Code** (расширение)
- [ ] Оплачена подписка **Claude** (Pro или Max)
- [ ] (Если из РФ) включён **VPN** одной страны

## Как запустить

**Через GitHub:** нажми «Use this template» → дай имя → склонируй к себе.

**Через терминал:**
```bash
git clone https://github.com/<твой-логин>/marat-v-coding-starter моё-пространство
cd моё-пространство
```

Дальше — открой в VS Code, открой Claude Code, напиши любую фразу. Остальное ИИ сделает сам.

## Что дальше

После знакомства просто ставь задачи — ИИ работает по твоему `my-brain/` и `CLAUDE.md`.
Скиллы из `skills/` подхватываются автоматически или вызываются напрямую (`/website-builder`).
