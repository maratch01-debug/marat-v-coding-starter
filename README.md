# marat-v-coding-starter

Стартовый шаблон для Claude Code, который **сначала узнаёт тебя, а потом работает под тебя.**

Клонируй → открой в VS Code → напиши любую фразу → ИИ проведёт тебя через знакомство (9 блоков
вопросов о тебе) и соберёт твой личный контекст: кто ты, к чему идёшь, каким голосом говоришь.
Дальше Claude — уже не обезличенный бот, а «свой».

---

## TL;DR

1. Забери шаблон себе (кнопка **«Use this template»** или `git clone`).
2. Открой папку в **VS Code**, открой **Claude Code**, напиши что угодно — `привет`.
3. ИИ сам начнёт знакомство и проведёт через 9 блоков (~40 минут, можно с паузами).
4. На выходе — твой **второй мозг** (`my-brain/`) + личный `CLAUDE.md`. Готово.

## Что ты получаешь

- 🧠 **`my-brain/`** — твой второй мозг: история, личность, ценности, цели, страхи, ниша, голос.
- 📋 **Личный `CLAUDE.md`** — правила, по которым ИИ работает именно под тебя.
- 🧰 **`skills/`** — 13 готовых скиллов Claude Code под сайты, контент и стратегию (полный список ниже).
- 📚 **`prompts/`** — библиотека промптов: критика плана, стресс-тест «10 причин».
- 🗂 **`plans/`** и **`sessions/`** — цикл работы и память между чатами.
- 🏗 **`business/`, `life/`, `references/`, `materials/`, `reels/`** — готовый каркас разделов
  (пустой, с описаниями) под весь твой бизнес и жизнь. Наполняешь под себя.

## 13 скиллов на борту

**Сайты:** website-builder (многостраничник с нуля) · landing-page (честный одностраничник) ·
marketing_laws (максимально продающий лендинг, 14-18 блоков + 48 законов власти) ·
design-system (палитра/шрифты/токены без «ИИ-дефолта») · site-redesign (апгрейд без поломки) ·
site-deploy (публикация в сеть + домен).

**Контент:** viral-remix (повторить чужую виралку своим голосом) · content-factory (1 сценарий
→ 21 единица контента: статья + 10 тредсов + 5 рилсов + 5 постов) · video-montage (монтаж
рилсов через ffmpeg: хук, вертикаль 1080×1920, субтитры, музыка) · blog-article (статья на сайт
по единой анатомии, SEO-инженерия) · humanizer-ru (27 паттернов ИИ-следов «до/после» —
зачищает текст до живого).

**Стратегия:** competitor-analysis (разбор конкурента по методу «границы»: механика → приёмы
влияния → обязательный вывод «берём / не берём»).

Подробно с таблицами «что делает / когда брать» — [skills/README.md](skills/README.md).

## Что можно построить за вечер

## 🔥 Прокачка окружения (опционально, но того стоит)

Кроме скиллов, Claude Code умеет ещё 4 вещи, которых нет «из коробки». Ставится одной командой:

- **Windows:** `powershell -ExecutionPolicy Bypass -File install-extras.ps1`
- **macOS/Linux:** `bash install-extras.sh`

Что даёт:
- **Память между сессиями** (плагин `claude-mem`) — ИИ помнит прошлые чаты, не читая их заново.
- **Свой браузер** (`agent-browser`) — ИИ сам открывает сайты и кликает, дешевле по токенам, чем стандартный Playwright.
- **Методология работы** (плагин `superpowers`) — сначала план и его критика, потом выполнение, вместо сразу «в бой».
- **Связка для генерации контента** (Higgsfield/HeyGen/ElevenLabs) — картинки, видео, говорящий аватар и голос прямо из чата. Эта часть опциональна и требует **своих** (платных) аккаунтов на этих сервисах — скрипт просто подключает их к Claude Code, регистрацию и оплату проходишь сам.

Первые три - бесплатные, ставятся сразу. Нужен установленный **Node.js** (для `npm`/`agent-browser`).
После установки перезапусти Claude Code.

## Зачем это нужно

Обычный ИИ отвечает «в среднем по больнице» — он тебя не знает. Этот шаблон меняет порядок:
**сначала ИИ узнаёт тебя глубоко, потом помогает.** Чем честнее ответишь на знакомстве — тем
точнее он будет попадать в тебя: твоим голосом, к твоим целям.

## Как запустить

**Через GitHub:** нажми «Use this template» → дай имя → склонируй к себе.

**Через терминал:**
```bash
git clone https://github.com/<твой-логин>/marat-v-coding-starter моё-пространство
cd моё-пространство
```

Дальше — открой в VS Code, открой Claude Code, напиши любую фразу. Остальное ИИ сделает сам.

## Что дальше

После знакомства просто ставь задачи — ИИ работает по твоему `my-brain/` и `CLAUDE.md`.
Скиллы из `skills/` подхватываются автоматически или вызываются напрямую (`/website-builder`).
